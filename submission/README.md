# AIN submission packaging

This repository is the clean P11 starter project. The course guide's three-folder
structure applies to the submission ZIP, not the GitHub repository root.

Required archive name: `61FIT3AIN-TUT02_G05_P11.zip`.

```text
61FIT3AIN-TUT02_G05_P11/
├── slides/
│   └── 61FIT3AIN-TUT02_G05_P11_midterm_slides.pdf
├── code/
│   ├── README.md
│   ├── requirements.txt
│   ├── app.py
│   ├── starter/
│   ├── scripts/
│   ├── tests/
│   └── data/  (small supplied/generated fixtures and manifests only)
└── report/
    └── 61FIT3AIN-TUT02_G05_P11_report.docx
```

## Guide requirements and implementation

| Guide section | Repository support | Remaining input |
|---|---|---|
| 2–3: names and ZIP structure | `scripts/package_submission.py` validates prefix and exactly one root with three folders | None for the known class/group/project |
| 4.1: original English midterm PDF | Copies the selected PDF byte-for-byte; excludes PPTX and extra PDFs | Confirm the exact originally presented deck; current `presentation.pdf` is unconfirmed |
| 4.2: Python 3.11 and runnable clean code | Pinned requirements, one-command Streamlit entry point, original starter tree, offline local CNN | Initial dependency installation requires a package source |
| 4.2: prohibited content | Explicit archive allowlist, tracked-file audit, ignored environments/caches/editor settings/secrets/full datasets | Never put credentials in source |
| 4.3: English DOCX, template, IEEE, 15–20 body pages | Template-based report builder, native equations and TOC/captions, Word pagination verifier | Obtain the official course template locally; use the IEEE edition |
| 4.3: Appendix B | Strict member/task/percentage/agreement validator | Agreed tasks and integer percentages totaling 100 |
| 5–6: size and verification | Archive CRC, required files, no extra report PDF, size below 50 MiB | Only the designated representative submits through the instructor's link |

The supplied checkpoint is generated by the team's training code and is allowed
under section 4.2. Full TrashNet train/validation/test images are excluded. Saved
measurements and small software fixtures remain available for offline inspection.
The real-camera and novel-campus evaluation sets remain uncollected; no results
are fabricated for them.

## Prepare local submission artifacts

From the repository root, use the Python 3.11 environment described in the main
README. Copy `submission/team.example.json` to `submission/team.json`, then enter
the actual member names, student IDs, tasks, integer contribution percentages,
and representative. Set agreement and slide-confirmation flags only after the
group has confirmed them. The local file is ignored by Git.

Obtain the instructor's original `AIN_Final_Report_Template.docx`. Keep the
original midterm PDF unchanged; renaming it inside the ZIP does not change its
contents. Build the English IEEE Word report:

```powershell
python -m pip install -r requirements-report.txt
python scripts/build_submission_report.py --template "PATH/TO/AIN_Final_Report_Template.docx"
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/render_submission_word.ps1 -InputDocx submission/61FIT3AIN-TUT02_G05_P11_report.docx -OutputPdf tmp/submission/report_final.pdf -UpdateFields
python scripts/verify_submission_report.py --docx submission/61FIT3AIN-TUT02_G05_P11_report.docx --pdf tmp/submission/report_final.pdf --template "PATH/TO/AIN_Final_Report_Template.docx"
python scripts/package_submission.py
```

The Word rendering helper requires Microsoft Word on Windows. Review the rendered
pages, especially the TOC, equations, tables, figures and Appendix B. The generator
uses fixed 15-page body layout to also respect the template's 15-page maximum.
If edited text changes pagination, revise and verify before packaging. Rebuilding
evidence figures also requires the original evaluation inputs; run the data and
experiment commands in the main README first.

The package command refuses unresolved contributions or unconfirmed slides. Use
`python scripts/package_submission.py --review` only for an explicitly incomplete
local review ZIP. It must not be described as submission-ready. Reports and ZIPs
are ignored by Git; their generation tools are versioned. The APA edition is a
separate formatting alternative and does not replace the required IEEE report.

## Check a clean checkout

```powershell
python scripts/check_submission_repo.py
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
python scripts/validate_checkpoint.py --image data/sample/paper/paper_01.png
python -m streamlit run app.py
```

GitHub is the source-code link required in the README. Pushing to GitHub does not
submit the course ZIP; submission is through the instructor's designated link.
